# Frontend — Next.js

Interfejs użytkownika w React i TypeScript, z App Routerem.

Z głównego katalogu projektu:

```bash
npm --prefix frontend run dev
```

Otwórz http://localhost:3000 i edytuj `src/app/page.tsx` w tym katalogu.

Pełna instrukcja instalacji i nauki: [główny README](../README.md).

[Dokumentacja Next.js](https://nextjs.org/docs/app/getting-started/installation)
